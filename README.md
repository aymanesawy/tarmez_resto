# الموبايل — Mobile Preview
صفحة معاينة تفاعلية تعرض **موقع المطعم الحقيقي** (نسخة `الحالي المطلوب قلب لغته`) داخل هاتف واقعي، بنفس نبرة واجهة المعاينة التفاعلية في المرجع (خلفية ليلية `#150D16`، لمسة وردية `#EF3982`، خط Cairo).

## التشغيل الطريقة الصحيحة
1. شغّل `start-preview.bat` (يخدم جذر مساحة العمل على `http://localhost:8080`)، أو نفّذ يدويًا:
   ```
   cd C:\Users\Al-Masa\Desktop\هنعمل تيست
   python -m http.server 8080
   ```
2. افتح `http://localhost:8080/الموبايل/` — أو افتح `index.html` مباشرة (file:// يعمل غالبًا، لكن الخادم المحلي أولى).
3. الخادم الخلفي (PHP/MySQL على :8000) غير مثبّت على هذا الجهاز → يظهر الموقع بالقائمة الاحتياطية المدمجة في كود `app.js` نفسه (بدون أي تعديل منّا).

## الملفات
- `index.html` / `style.css` / `script.js` — الصفحة المستقلة
- `start-preview.bat` — مشغّل الخادم المحلي

أدوات المعاينة: تحديث · تبويب مستقل · حجم (375/390/430) · وضع سطح مكتب 1280×800 · تبويبات صفحات الموقع (الرئيسية/السلة/التتبع/الدخول).
